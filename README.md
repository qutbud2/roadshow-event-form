# Roadshow Event Request & Success Advisor

Static web app for standardized roadshow requests, readiness scoring, best-practice recommendations, proven roadshow activities, and automatic task-plan generation.

## Render
Deploy as a Static Site with publish path `.` and no build command required.

## Future automation
The form currently generates a JSON payload and 23-task execution plan in the browser. A future Power Automate or backend endpoint can create Planner tasks and Teams notifications automatically.
